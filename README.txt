VAELEN STATIC WEBSITE — HTML, CSS AND JAVASCRIPT ONLY

Open index.html in a browser, or use VS Code Live Server.
Pages: homepage, shop, collections, about, product details, cart, checkout demo, search, account preview, contact, shipping & returns, FAQs, privacy, terms, journal, and five article pages.
Shared files: css/style.css and js/main.js. SEO support: sitemap.xml and robots.txt.

IMPORTANT:
- Replace https://www.example.com in canonical tags, Open Graph URLs and sitemap.xml with your real domain.
- Product details, images, and prices are sample/demo content.
- Cart data is stored in browser localStorage only.
- Checkout does not process payment or create real orders.
- Contact/newsletter forms do not send messages or save subscriber data.
- No secure authentication, database, inventory, admin system, or backend is included.
- Connect a secure backend, database, payment gateway, order management and email provider before accepting real orders.
- Images and Google Fonts are loaded from external services and require internet access.
- Replace sample privacy, terms, shipping, and returns copy with your actual policies before launch.
